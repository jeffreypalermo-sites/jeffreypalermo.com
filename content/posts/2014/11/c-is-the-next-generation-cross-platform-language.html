I remember computer science class at Texas A&M University where I was learning Java as a write-once-run-anywhere language.

Now, so many years later, C# is emerging as the language to build

  • Windows apps
  • Web apps
  • Linux apps
  • Mac apps
  • iOS apps
  • Android apps
  • Windows Phone apps
  • XBox apps
  • SPA apps
  • JavaScript apps
  • Database apps
  • Cloud apps
  • and more

Today, Microsoft announced so many things.  I’ll just list them here and let you follow the links

  • .Net 2015 will be released with Windows, Linux, and Mac CLRs supported by Microsoft and OSS on GitHub
  • Visual Studio 2013 Community is a free “almost pro” edition that supports all project types as well as extensions (Hello ReSharper)
  • ASP.NET MVC 6 will be included with Visual Studio 2015 and will be based completely on the OWIN stack introduced with Web API
  • Scott Guthrie and Soma Somaseger make all the big announcements at the Connect conference – and lots of other videos are available as well (the event RSS feed is broken on Channel 9 – for podcatchers, so you’ll have to go to the videos individually)
