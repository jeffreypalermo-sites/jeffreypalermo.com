With the imminent release of ASP.NET MVC, the industry is buzzing about this new way to write ASP.NET applications (not really new – i.e. MonoRail).  Lots of folks are already intending to adopt this library when it is released, so Headspring Systems is sponsoring a free afternoon of ASP.NET MVC framework training at the Microsoft office in Austin, TX.   Make sure to register for this event because there is a limited number of chairs.

Details:

Austin: An afternoon of Asp.Net MVC, with Headspring Systems

Thursday, February 19, 2009 from 1:00 PM – 4:30 PM (CT)

Microsoft office classroom, Austin, TX

An afternoon of Asp.Net Mvc training that will go into the insides of the Asp.Net mvc framework.  Students will learn how to use this framework to build a real application. Benefit from the work that Headspring Systems has done with developing applications on the framework for its clients and learn what they have about the do’s and don’ts on Microsoft’s new web framework. 

The following topics will be covered:

  • What is MVC
  • Routing
  • Testing
  • View Engines
  • Controller Factory
  • ModelBinders
  • Action Filters

For More information about Headspring Systems goto www.HeadspringSystems.com
