# Architecture decision records

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-onion-architecture.md) | Onion Architecture with a dependency-free Core | Accepted |
| [0002](0002-git-is-the-system-of-record.md) | Git is the system of record; in-memory read model; no database in v1 | Accepted |
| [0003](0003-azure-container-apps.md) | Host on Azure Container Apps | Accepted; delivery and hosting details superseded by 0006 |
| [0004](0004-legacy-url-resolution-in-core.md) | Legacy URL resolution is domain logic, verified by the URL contract | Accepted |
| [0005](0005-blazor-static-ssr.md) | Blazor static SSR, no client runtime | Accepted |
| [0006](0006-deliver-through-the-demo-environment-kit.md) | Deliver through the demo-environment-kit GitOps system | Accepted; who creates the site's runtime changed by 0007 |
| [0007](0007-the-site-owns-its-runtime.md) | The site owns its runtime; the system gives it the pipeline | Accepted |
| [0008](0008-eleven-regions-behind-front-door.md) | Eleven regions behind Azure Front Door, in rotation, each scaling to zero | Accepted |
| [0009](0009-the-wordpress-look-and-navigation.md) | Keep the WordPress site's look and navigation; Razor components rendered from the existing routes | Accepted; the look superseded by 0019 |
| [0010](0010-the-wordpress-site-is-frozen.md) | The WordPress site is frozen; content is edited in git | Accepted |
| [0011](0011-the-systems-dashboard-reads-the-site.md) | The system's health dashboard reads the site from the browser | Accepted |
| [0012](0012-the-site-publishes-its-build-facts.md) | The site publishes the facts of its build: the Build writes them, the image carries them, `/_build` answers them | Accepted |
| [0013](0013-the-front-door-keeps-the-sites-answers.md) | The Front Door keeps the site's answers at its edge (a browser 5 minutes, the edge 7 days); a deployment empties it; a failed step against Azure is run once more | Accepted |
| [0014](0014-the-custom-domain-prepared.md) | The custom domain is prepared and switched off: host names per environment in the settings (no name of `jeffreypalermo.com` in production yet), a custom domain and a managed certificate for each, `www.` and `feeds.` on a route without a cache; the DNS move is a runbook | Accepted; the canonical host and the redirects by host changed by 0024 |
| [0015](0015-recordings-wait-for-the-reader.md) | A recording is played by the browser's own player, which waits for the reader; a link to the file beside it | Accepted |
| [0016](0016-the-dns-zone-as-code.md) | The domain's DNS is an Azure DNS zone, as code: every record of the inventory, an alias of the Front Door at the top, a stack of its own that never deletes; created before it is delegated, and delegated by a person | Accepted |
| [0017](0017-a-picture-leads-to-a-file-or-the-post-says-it-is-gone.md) | A picture on this site leads to a file, or the load fails; the uploads listed as lost are the exception; `recover` finds what the Wayback Machine has, and a picture no source has gives way to a note | Accepted |
| [0018](0018-the-environments-own-names.md) | Every environment has a name of its own in `jeffreypalermo.ceo`: `www.` for production and `uat.` as custom domains of their Front Doors, `tdd.` as a forwarding at GoDaddy; uat's name is the rehearsal of the DNS move | Accepted; the second copy to a search engine closed by 0024 |
| [0019](0019-the-masthead-look.md) | The look is "Masthead", in Clear Measure's colours: a navy masthead with a yellow rule, the posts set like articles, the index beside them. One stylesheet for the markup, the navigation and the addresses of 0009; no script, no new font, nothing that moves | Accepted |
| [0020](0020-the-podcasts-episodes-are-posts.md) | Every episode of the podcast is a post, dated as the show published it, written once by `WpMigrator podcast` from the show's feed and edited in git from then on. The recording is played by the browser's player. The video is embedded at the top of the post in a frame that asks YouTube for nothing until the reader presses play: its document is in the page itself, the site's own poster inside a link to the player | Accepted |
| [0021](0021-the-menu-leads-to-the-podcast-and-the-books.md) | The menu leads to the podcast and to the books: "AI DevOps Podcast" is a new entry, "Books" (the tag) replaces ".NET DevOps for Azure". Every episode is in the category of the show's present name. The book *The Five Pillars* has a post | Accepted |
| [0022](0022-the-home-page-and-the-feed-leave-out-the-episodes.md) | The home listing (`/`, `/page/N/`) and the site's own feeds list every post that is not an episode of the podcast; every other listing, the sitemap and previous/next take an episode as any post. One rule in Core: `PodcastEpisodes` | Accepted |
| [0023](0023-the-front-doors-access-log.md) | The Front Door's access log is kept: a setting per environment (`uat` and `prod`), a Log Analytics workspace and one diagnostic setting in the site's own stack, 30 days, at most 1 GB a day; access log only. Switched off, the stack deletes the workspace; `deploy.ps1` prints where the log is and a query by status code | Accepted |
| [0024](0024-the-canonical-host-is-www-jeffreypalermo-ceo.md) | The canonical host is `www.jeffreypalermo.ceo`: feeds, sitemaps, `robots.txt` and each page's absolute `rel="canonical"` link name it under every host. The hosts answered with a redirect are two lists the settings state and the site shares, both empty: no host is redirected. Feed items keep the identifiers they were published with | Accepted |
| [0025](0025-each-instance-counts-its-last-minute.md) | Each running instance counts what it answered in the last minute and answers it at `/_telemetry`: traffic through the Front Door and direct, errors, the 95th percentile, the checks apart; numbers only, in memory, no timer; the dashboard that reads it wakes the regions | Accepted |
| [0026](0026-the-site-sleeps-without-its-front-doors.md) | While the fleet sleeps, the site is deployed without its Front Doors: `"dormant": true` at the top of the settings leaves out every environment's Front Door, host names and access log, and the site's stack deletes them; the decided settings stay as they are, the regions run and the DNS zone keeps its records. Waking is `"dormant": false` and a promotion | Accepted |
| [0027](0027-one-command-is-the-private-build.md) | One command is the private build: `pwsh ./build.ps1` compiles with warnings as errors and runs the unit and the integration tests; the Build's job test runs it and nothing else of the compile and the tests; its word reaches the facts as `build` (`ranBy` `integration`, `run` the Build's run), which the fleet reads as "Private build" | Accepted |

The overall design is in [docs/architecture](../architecture/README.md). The one runbook is
[docs/runbooks/dns-cutover.md](../runbooks/dns-cutover.md): moving `jeffreypalermo.com` to the new site.
